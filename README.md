# 🏫 Harrow School S.A.C. — Sitio Web Institucional

Sitio web institucional de **Harrow School S.A.C.**, institución educativa privada de nivel primaria y secundaria ubicada en **Nuevo Chimbote, Áncash, Perú**.

🌐 **[grupo01presentacion.lat](https://grupo01presentacion.lat)**

---

## 📋 Descripción

Página web desarrollada como proyecto académico para presentar la oferta educativa, equipo docente, proceso de admisión y canales de contacto de Harrow School S.A.C. El sitio incluye formularios de contacto y admisión funcionales con envío de correo electrónico.

---

## 📄 Páginas

| Página | Descripción |
|--------|-------------|
| `index.html` | Inicio — Hero, servicios, áreas académicas, equipo y testimonios |
| `about.html` | Nosotros — Misión, visión e historia institucional |
| `cursos.html` | Áreas Académicas — Las 8 áreas curriculares |
| `equipo.html` | Nuestro Equipo — Docentes destacados |
| `admision.html` | Admisión 2026 — Requisitos y formulario de solicitud |
| `testimonial.html` | Testimonios — Opiniones de familias y alumnos |
| `contact.html` | Contacto — Formulario, mapa y redes sociales |

---

## ✨ Características

- ✅ Diseño responsivo con **Bootstrap 5**
- ✅ Animaciones con **Animate.css** y **WOW.js**
- ✅ Carrusel de imágenes con **Owl Carousel**
- ✅ Formulario de contacto con envío de correo vía **Web3Forms**
- ✅ Formulario de admisión con validaciones y envío vía **Web3Forms**
- ✅ Validaciones en tiempo real (nombre, correo, teléfono, etc.)
- ✅ Mapa embebido de Google Maps
- ✅ Integración con WhatsApp, Facebook, Instagram y YouTube
- ✅ Dominio personalizado `.lat`
- ✅ HTTPS habilitado

---

## 🛠️ Tecnologías utilizadas

- HTML5, CSS3, JavaScript (ES6)
- Bootstrap 5
- Font Awesome 5
- Google Fonts (Heebo + Nunito)
- Owl Carousel
- WOW.js + Animate.css
- Web3Forms (envío de formularios)

---

## 🚀 Despliegue

El sitio está desplegado en **GitHub Pages** con dominio personalizado adquirido en **Namecheap**.

```
Namecheap (.lat) → DNS Records → GitHub Pages → grupo01presentacion.lat
```
